# MCMEG.UFMG Website

The official website of MCMEG (Monte Carlo Modelling Expert Group), an expert network group established
in 2016 and hosted at the Post-Graduate Program in Nuclear Sciences and Techniques, UFMG, Belo Horizonte,
Brazil. Made by Telma Fonseca and the MCMEG team.

Plain static HTML/CSS/JS, no build step — served via GitHub Pages.

## Structure

- `index.html` — home
- `about.html` — mission, team, funding
- `book.html` — Computational Experiments in Radiation Physics
- `course.html` — Introduction to the Monte Carlo Method
- `students.html` — student profiles
- `contact.html` — community links
- `assets/` — shared stylesheet, script, and images
